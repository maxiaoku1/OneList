# MonoMinimalist 主题

极简黑白灰风格的 OneList 主题，提供 Light/Dark 日夜模式、列表/卡片双视图切换，以及统一的胶囊按钮交互。文件名旁带有黑白线框的类型标签，移动端同样优化为单列布局并保留视图切换能力。

## 特性
- 黑白灰阶配色，内建 Light/Dark 切换，覆盖背景/文字/边框/hover/active/focus/disabled。
- 列表视图 & 卡片视图一键切换，布局自动适配移动端（≤768px 单列、可切换视图、触控热区≥44px）。
- 全站胶囊按钮（统一高度/圆角/padding/字体/状态），交互一致。
- 引入黑白线框极简图标，贴近 Apple/Notion 风格。
- 文件名旁显示类型标签（IMG/VID/PDF/DOC/XLS/ZIP/TXT/AUD 等），纯线框黑白无渐变/阴影。

## 使用
将 `index.html` 作为 OneList 的模板文件，启动服务后即可使用新主题。
